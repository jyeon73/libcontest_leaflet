# 국립중앙도서관 소장자료 지도 탐험 서비스

2026 도서관 데이터 활용 공모전 출품작 (월수팀) — 서울 지도 위 역사적 장소를 클릭하면 국립중앙도서관(국중도) 소장 자료를 탐색할 수 있는 웹 서비스입니다.

## 프로젝트 소개

지도를 메인 산출물이 아닌 **매개체**로 삼아, 이용자가 능동적으로 국중도 소장 자료를 탐색하는 경험을 제공하는 것을 목표로 합니다. AI는 정보를 대신 요약해 떠먹여주는 역할이 아니라, 방대한 검색결과 중 이용자 질문과 관련도 높은 자료를 선별해주는 역할로 제한했습니다.

## 주요 기능

### 1. 지도 기반 장소 탐색
- Leaflet.js로 구현한 서울 지도
- 5개 역사적 장소에 핀 표시: 경복궁 / 서대문 독립문·서대문형무소 / 마포 양화진·절두산 / 노량진·한강철교 / 숙명여대·효창공원
- 핀 클릭 시 오른쪽 패널에 해당 장소와 연결된 자료 카드(이미지·설명·원문 링크) 표시
- 자료가 여러 건일 경우 이전/다음 버튼으로 넘겨보는 캐러셀 방식

### 2. AI 사서 챗봇 (실시간 검색 기반)
- 이용자가 질문을 입력하면 해당 장소명을 키워드로 **국립중앙도서관 Open API(국가자료종합목록)**를 실시간 검색
- GPT는 검색결과 목록 중 질문과 관련도 높은 항목만 **선별**(생성이 아님) — 사전지식으로 답을 지어내지 않도록 시스템 프롬프트로 제한
- 선별된 인덱스에 해당하는 실제 메타데이터(제목, 저자, 발행연도, 소장위치, 원문 링크)를 그대로 카드로 렌더링해 환각(hallucination) 위험을 최소화
- GPT에 넘기는 입력과 출력을 모두 짧게 제한(메타데이터 요약 + 인덱스/한줄 이유)해 토큰 사용량을 낮춤

## 기술 스택

| 구분 | 기술 |
|---|---|
| 지도 | Leaflet.js 1.9.4, OpenStreetMap 타일 |
| 프론트엔드 | HTML / CSS / Vanilla JavaScript |
| 백엔드 | Vercel 서버리스 함수 (Node.js) |
| 외부 API | 국립중앙도서관 Open API(국가자료종합목록), OpenAI API(gpt-4o-mini) |
| 배포 | Vercel + GitHub 연동 자동 배포 |

## 폴더 구조

```
leaflet-project/
├── index.html          # 지도 + 사이드 패널(카드 영역/챗봇 영역) 마크업
├── app.js              # 지도 초기화, 마커, 카드 렌더링, 챗봇 프론트 로직
└── api/
    └── chat.js         # 국중도 API 검색 + GPT 선별 로직 (서버리스 함수)
```

## 환경변수

Vercel 프로젝트 설정(Settings → Environment Variables)에 아래 두 개를 등록해야 합니다. 프론트엔드 코드에는 어떤 API 키도 직접 포함되지 않습니다.

| 변수명 | 설명 |
|---|---|
| `OPENAI_API_KEY` | OpenAI API 키 (GPT 자료 선별용) |
| `NL_API_KEY` | 국립중앙도서관 Open API 인증키 |

## 실행 방법

1. 저장소 클론 후 VS Code로 폴더 열기
2. `index.html`을 Live Server로 실행하면 지도와 정적 자료 카드까지는 로컬에서 확인 가능
3. 챗봇 기능(`/api/chat`)은 Vercel 서버리스 함수이므로 **로컬 Live Server에서는 동작하지 않으며, 배포된 Vercel 주소에서만 테스트 가능**
4. 코드 수정 후 `git add . && git commit -m "메시지" && git push` 시 Vercel이 자동 재배포
