# 국립중앙도서관 소장자료 지도 탐험 서비스

2026 도서관 데이터 활용 공모전 출품작 (월수팀) — 서울 지도 위 역사적 장소를 클릭하면 국립중앙도서관(국중도) 소장 자료를 시대별로 탐색할 수 있는 웹 서비스입니다.

배포 주소: https://libcontest-leaflet.vercel.app

## 프로젝트 소개

지도를 메인 산출물이 아닌 **매개체**로 삼아, 이용자가 능동적으로 국중도 소장 자료를 탐색하는 경험을 제공하는 것을 목표로 합니다. AI는 정보를 대신 요약해 떠먹여주는 역할이 아니라, 방대한 검색결과 중 이용자 질문과 관련도 높은 자료를 선별해주는 역할로 제한했습니다.

## 주요 기능

### 1. 지도 기반 시대별 자료 탐색
- Leaflet.js + CartoDB Light 타일(채도 보정)로 구현한 서울 지도
- 5개 역사적 장소를 원형 엠블럼 마커로 표시: 경복궁 / 서대문형무소 / 마포 양화진·절두산 / 노량진·한강철교 / 효창공원
- 초기 화면은 지도만 전체화면으로 보이고, 장소를 클릭해야 사이드 패널(자료·메모·챗봇)이 열림
- 마커에 마우스를 올리면 해당 장소의 대표 자료 이미지가 미리보기로 표시됨
- 각 장소는 조선시대·근대·현대 등 **시대별 탭**으로 구분되어 있으며, 탭 전환 시 그 시대의 역사 설명(연도 강조)과 해당 시기 소장자료가 함께 전환됨
- 자료가 여러 건이면 가로 썸네일로 나열, 클릭 시 상세 카드(이미지·제목·저자·발행처·발행일·비고·원문 링크) 표시
- 현재 5개 장소 · 13개 시대 구간 · 총 39건의 자료(신문/고문헌/도서/이미지 등, 대표 이미지 39장 포함)가 정리되어 있음

### 2. 즐겨찾기 · 개인 메모
- 장소별 즐겨찾기 토글 — 지도 마커에 별 표시로 즉시 반영
- 장소별 자유 메모 작성/저장
- 둘 다 `localStorage`에 저장되어 재방문 시에도 유지됨(로그인 없이 브라우저 기준)

### 3. AI 사서 챗봇 (RAG 기반 자료 선별)
장소를 선택한 상태에서 자연어로 질문하면, 아래 순서로 동작합니다.

1. **질의 이해** — GPT-4o-mini가 질문 + 선택된 장소명으로 검색 키워드를 추출 (합성 지명은 핵심 지명 한 단어로 축약, 예: "마포 양화진·절두산" → "마포")
2. **실시간 검색** — 추출한 키워드로 국립중앙도서관 Open API(KOLIS-NET)를 실시간 검색. 국중도 검색은 여러 단어를 AND로 매칭해 0건이 되기 쉬우므로, ①GPT 키워드 → ②장소 전체 명칭 → ③장소 핵심 명칭 순으로 재시도하는 폴백 로직과, GPT가 깨진 값이나 "장소"·"서울" 같은 지나치게 일반적인 단어를 내놓는 경우를 걸러내는 검증(`isUsableKeyword`) 로직 포함
3. **자료 선별** — 검색결과 목록 중 질문과 관련도 높은 항목만 GPT가 **선별**(생성이 아님) — 목록에 없는 내용을 만들지 않도록 시스템 프롬프트로 제한, 응답은 인덱스 + 한줄 이유만 담은 JSON으로 강제
4. **근거 기반 출력** — 선별된 인덱스에 해당하는 실제 메타데이터(제목·저자·발행연도·원문 링크)를 그대로 카드로 렌더링해 환각(hallucination) 위험을 구조적으로 차단

### 4. PC / 모바일 반응형
동일 코드베이스에서 CSS 미디어 쿼리(768px 기준)로 화면을 분기합니다.

| 구분 | PC | 모바일 |
|---|---|---|
| 레이아웃 | 좌우 분할 (지도 65% + 패널 35%) | 상하 분할 (지도 42% + 패널 58%) |
| 마커 크기 | 74px | 46px |
| 자료 상세 확인 | 썸네일 클릭 → 패널 내 카드 갱신 | 썸네일 탭 → 전체화면 사진 모달(좌우 스와이프로 자료 전환) |
